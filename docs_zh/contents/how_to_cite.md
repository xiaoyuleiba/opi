
# 如何引用

使用 OPI 时，请引用实际使用的相应版本。 

:::{admonition} **OPI 参考文献**
:class: tip
FACCTs GmbH. OPI (Version v1.0). https://github.com/faccts/opi. DOI: 10.5281/zenodo.15688425
:::

可根据需要调整以下引用格式。

```{code-block} text
:caption: BibTeX

@software{opi_v1.0,
  author       = {{FACCTs GmbH}},
  title        = {OPI},
  version      = {v1.0},
  doi          = {10.5281/zenodo.15688425},
  url          = {https://github.com/faccts/opi},
}
```
